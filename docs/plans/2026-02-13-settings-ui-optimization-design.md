# 设置页面 UI 优化设计文档

_创建日期: 2026-02-13_

## 背景

当前设置页面存在以下问题：
1. **页面太长，难以导航** - 用户需要滚动很多才能找到需要的设置项
2. **代理设置太复杂** - 代理配置区域有大量字段和绑定选项，操作困难

## 设计目标

- 减少页面视觉负担，提高设置项的可发现性
- 简化代理配置流程，降低使用门槛
- 保持现有功能完整性

## 方案概述

采用**标签页导航 + 可折叠区块**的方案重构设置页面。

## 整体架构

```
┌─────────────────────────────────────────────────────────┐
│  [通用]  [安全]  [代理]  [外观]  [高级]                    │  ← 顶部标签导航
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [当前标签内容区域]                                       │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │  设置区块 1                                      │   │
│  │  (可折叠，默认展开)                               │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 标签页设计（5个标签）

| 标签 | 包含内容 |
|------|---------|
| **通用** | 本地模式信息、数据管理、路由偏好 |
| **安全** | 登录验证开关、密码修改 |
| **代理** | 代理配置（简化版）、代理配置文件、提供商绑定 |
| **外观** | 主题设置（暗色/亮色/系统） |
| **高级** | 可观测性设置、调试选项 |

## 组件设计

### 1. 标签导航组件 (SettingsTabs)

**位置：** 页面顶部，固定显示

**样式：**
- 水平排列的标签按钮
- 当前激活标签有高亮样式
- 支持键盘导航

**状态管理：**
- 使用 URL query 参数 `?tab=xxx` 保持标签状态
- 支持直接链接到特定标签

### 2. 可折叠卡片组件 (CollapsibleCard)

**功能：**
- 点击标题栏展开/收起内容
- 展开状态可通过 prop 控制
- 带有展开/收起动画

**默认状态：**
- 首要设置区块默认展开
- 次要设置区块默认收起

### 3. 代理设置简化版

**简化输入模式（默认显示）：**
```
┌─────────────────────────────────────────────────────────┐
│ 代理服务器                                              │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ 协议 [HTTP ▼]  地址 [127.0.0.1    ] 端口 [7890   ]  │ │
│ │                                [测试连接]            │ │
│ └─────────────────────────────────────────────────────┘ │
│ [展开高级选项 ▾]                                        │
└─────────────────────────────────────────────────────────┘
```

**高级选项（展开后）：**
- HTTP 代理、HTTPS 代理、ALL 代理分开配置
- No Proxy 排除列表

### 4. 代理配置文件卡片

**卡片列表样式：**
```
┌─────────────────────────────────────────────────────────┐
│ 🇺🇸 美国节点              [测试] [编辑] [删除]           │
│ http://127.0.0.1:7890                                   │
│ ─────────────────────────────────────────────────────── │
│ 已绑定: claude, openai, cursor                          │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│ 🇭🇰 香港节点              [测试] [编辑] [删除]           │
│ socks5://192.168.1.100:1080                             │
│ ─────────────────────────────────────────────────────── │
│ 已绑定: gemini                                           │
└─────────────────────────────────────────────────────────┘
```

**功能：**
- 点击卡片展开编辑详情
- 快捷测试连接按钮
- 显示已绑定的提供商

### 5. 提供商代理绑定表格

**表格样式：**
| 提供商 | 代理配置 | 操作 |
|--------|----------|------|
| Claude | [使用全局 ▼] | 测试 |
| OpenAI | [美国节点 ▼] | 测试 |
| Gemini | [香港节点 ▼] | 测试 |

**功能：**
- 下拉选择代理配置
- 快速测试当前绑定
- 批量操作按钮

## 数据流

1. 页面加载时获取所有设置数据
2. 标签切换不重新获取数据
3. 设置修改即时保存（当前行为）
4. 代理配置文件保存需要显式点击保存按钮

## 文件结构

```
src/app/(dashboard)/dashboard/profile/
├── page.js                    # 主页面（包含标签导航）
├── components/
│   ├── SettingsTabs.js        # 标签导航组件
│   ├── GeneralTab.js          # 通用设置标签
│   ├── SecurityTab.js         # 安全设置标签
│   ├── ProxyTab.js            # 代理设置标签
│   ├── AppearanceTab.js       # 外观设置标签
│   ├── AdvancedTab.js         # 高级设置标签
│   ├── ProxyProfileCard.js    # 代理配置卡片
│   └── ProviderBindingTable.js # 提供商绑定表格
```

## 实现步骤

### 阶段 1: 基础结构
1. 创建标签导航组件
2. 重构主页面结构
3. 拆分现有代码到各标签组件

### 阶段 2: 代理设置优化
1. 实现简化的代理输入模式
2. 创建代理配置文件卡片组件
3. 实现提供商绑定表格

### 阶段 3: 细节优化
1. 添加 URL 参数支持
2. 优化加载状态和错误提示
3. 测试所有功能

## 兼容性考虑

- 保持现有 API 接口不变
- 数据结构与现有数据库兼容
- 支持移动端响应式布局

## 风险评估

- **低风险**: 标签导航组件、拆分代码
- **中风险**: 代理设置简化逻辑（需确保功能完整）
- **缓解措施**: 保持原有高级选项可访问

## 验收标准

1. 设置页面可通过标签快速导航
2. 代理配置流程简化，新用户可快速上手
3. 所有现有功能保持可用
4. 页面加载性能不受影响
